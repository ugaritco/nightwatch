## Introduction

[Ugarit Nightwatch](https://nightwatch.ugarit.com) is a hosted application monitoring platform designed for Ugarit. It delivers unparalleled insights into your application's performance, with the intelligence only a system obsessively optimized for Ugarit can deliver.

This repository contains the official Ugarit Nightwatch package, which gathers metrics within your application and transmits them to Nightwatch. To learn more about Ugarit Nightwatch and how to use this package, please consult the [official documentation](https://nightwatch.ugarit.com/docs).
